# Personal Markdown Knowledge Base

面向学生与知识工作者的 Windows 11 个人本地 Markdown 笔记与知识管理工具，围绕“记录—组织—查找—关联—输出”流程组织需求。

## 项目目标

支持 Markdown 编辑与预览、标签、全文检索、双向引用、单篇 Markdown 导出、手动保存，以及手动备份和独立恢复。首版支持一个活动笔记集合的新建、打开和切换。

首版不包含移动端、多人协作、多设备同步、插件或主题扩展、AI 问答及 OCR，也不包含集合删除、合并、并行打开或跨集合引用。

## 目前阶段

当前为需求分析第二版定稿阶段。新增规则涵盖名称100个Unicode码点、标签30个码点及每篇20个不同标签、默认导出命名，以及携带集合与笔记标识的内部引用。跨集合复制不能误关联；恢复只转换恢复产物中的引用归属，保留对应关系。

系统尚未开发；功能、性能、离线和故障等运行验收均未执行。性能指标仅为后续验收目标，1000篇/10 KB不是笔记容量上限。

完整范围、优先级、来源、验收方法及场景追踪见[需求分析文档](docs/requirements.md)。课程协作记录、人工核实说明和提交包不上传本仓库。

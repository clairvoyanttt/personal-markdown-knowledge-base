# Personal Markdown Knowledge Base

面向学生与知识工作者的 Windows 11 个人本地 Markdown 笔记与知识管理工具，围绕“记录—组织—查找—关联—输出”流程组织需求。

## 项目目标

支持 Markdown 编辑与预览、标签、全文检索、双向引用、单篇 Markdown 导出，以及手动保存、备份和独立恢复。核心功能离线可用。

首版不包含移动端、多人协作、多设备同步、插件或主题扩展、AI 问答及 OCR。

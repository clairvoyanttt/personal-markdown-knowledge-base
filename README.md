# Personal Markdown Knowledge Base

面向学生与知识工作者的 Windows 11 个人本地 Markdown 笔记与知识管理工具，围绕“记录—组织—查找—关联—输出”流程组织需求与设计。

## 项目目标

支持 Markdown 编辑与预览、标签、全文检索、双向引用、单篇 Markdown 导出、手动保存，以及手动备份和独立恢复。首版支持一个活动笔记集合的新建、打开和切换。

首版不包含移动端、多人协作、多设备同步、插件或主题扩展、AI 问答及 OCR，也不包含集合删除、合并、并行打开或跨集合引用。

## 文档入口与目前阶段

- [需求分析文档](docs/requirements.md)：第一关第二版定稿，保留原需求及编号。
- [软件设计文档](docs/design.md)：实验二定稿，覆盖架构、模块、流程、接口、数据一致性、界面、设计权衡、18条需求追踪及验证计划。

设计采用 C#／.NET 10／WPF 和每集合独立 SQLite；这些是设计选择，不是第一关指定实现。CB01、CB02 分别作为后续边界澄清和极端异常设计列明，第一关需求文件未改写。

系统尚未开发，没有可运行软件。功能、性能、离线、故障、隐私、兼容性及模块契约验收均未执行。独立 SQLite 小样例仅核对部分 SQL 关系，不是产品验收。性能指标仍为目标，1000篇／10KB不是容量上限。

本仓库只公开适合公开的项目文档；课程 ZIP、私有脚本、原始检查记录和聊天内容不上传。

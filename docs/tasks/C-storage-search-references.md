## 必须守住的规则

- 名称裁剪后1—100码点，英文判重不分大小写且排除自身；标签1—30码点/每篇20个，区分大小写，重复不增加计数。先拒绝C0/DEL、单行禁U+2028/2029和非法代理项，再按明确空白规则裁剪；不能用casefold扩大名称判重语义。
- 每连接外键ON；Notes与LIVE身份双向一致、源修订复合唯一/外键、删除出站/标签级联、入站保留。应用还要检查码点数量、跨度、回执语义及版本，不能声称DDL包办全部规则。
- 同一集合串行写入，连接在拥有它的存储线程内使用；显式BEGIN/COMMIT/ROLLBACK且核实结果，避免Python sqlite3隐式事务与延迟外键混用。
- 引用先判断集合再判断笔记身份；改名不换绑、删除后不复活，缺失/删除身份可保留。代码/外链/图片保护；Python码点与UTF16位置显式转换。
- 保存前不更新搜索/筛选/其他笔记反向引用；不自动保存。搜索是连续字面匹配，英文不分大小写，空/零结果可辨。
- 回执须匹配集合/命令/笔记/版本/操作及内容；旧集合/恢复初始化不能证明SAVE；缺回执不单独证明未提交。

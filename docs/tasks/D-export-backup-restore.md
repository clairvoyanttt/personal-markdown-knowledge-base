## 关键验收

- FR09：只用已保存单篇Markdown；未保存先提示，无保存版本不可导出。有效/失效引用变普通文本，保留确认的前缀/限制/原因；不是v3应用UI提示。外部链接、代码、图片路径不改，附件不打包。
- 默认`note-<处理后的已保存名>.md`，Windows禁用字符替换下划线、移除末尾点/空格；合法用户文件名最终.md；既有文件拒绝覆盖。
- FR11：备份只用保存版，所有草稿类型都提示；冻结源集合，快照是业务权威，manifest记录来源位置/实际捕获UTC时间/保存数量等并核对。
- 恢复只到空位置新集合，不覆盖/合并，不自动打开；源位置仅识别，不要求仍可访问；原集合和备份不修改。
- 原有效/已删/缺失/第三集合引用分别处理，正常失效不当损坏；只改恢复产物归属。按笔记创建RESTORE_NOTE_INIT，旧回执不移作新SAVE证据。
- 发布/配置未知报告UNCONFIRMED，不当SAVE核实；错误不能随意删除可能正式的文件；ZIP拒绝目录穿越、重复/缺失关键条目。

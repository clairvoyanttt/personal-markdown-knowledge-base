## 6. 诚实性检查

提交记录前逐项确认：

- [ ] 执行人和复核人是真实参与者，AI 没有被写成人工执行人。
- [ ] 应用版本、提交、Windows、Python、Qt、设备和目录权限来自实际机器。
- [ ] 数据集清单中的集合 ID、数据库 SHA-256、笔记数、字节范围和引用数来自实际生成。
- [ ] 预热、等待、查询间隔、顺序和计时方法与本文一致；没有删掉慢查询后只报快值。
- [ ] 所有 30 条都有实际条数、摘要和耗时；失败条目保留错误和现场。
- [ ] 工具自检或自动测试的结果没有被填成“正式 V10 通过”。
- [ ] 真实笔记、用户目录、日志、截图、数据库和安装包没有上传公开仓库。

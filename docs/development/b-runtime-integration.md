## 本轮补齐与运行检查

- 已接入保存版删除确认。存在未保存修改时先阻止删除，提示先保存；模态确认期间再编辑会使确认失效。使用确认时的保存修订，不能自动删除后来更新的保存版。
- 已知删除未提交：保留原保存版及草稿，刷新后可重新确认。删除结果未知：保留输入，禁止重复删除、保存、集合切换；核实按钮只读一致快照，核对原命令/操作标识、DELETE 回执和已删除身份。缺少回执仍是未知，不把未知写成未提交。退出未知状态另有风险确认。当前 C 没有提供能证明未知删除未提交的窄端口，所以这种情况保守保持待核实，不自动重放。
- 旧适配器在独立回收线程关闭，既不阻塞 Qt，也不依赖运行时接受新任务；关闭流程仍拥有全部适配器并等待回收线程结束。
- 未保存引用预览消费共享解析与保存版目标分类，显示已保存目标名；代码中的标记保留原文，不新增反向引用。
- 增加插入选中保存版引用、空搜索清除旧结果、非法标签筛选反馈，以及三种保存核实状态的区分提示。

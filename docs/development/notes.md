# 开发注意事项（四人共同遵守）

1. **不要伪造完成**：当前仅启动基线。未实现服务不能返回保存成功/备份成功；基础检查不代表完整产品V01—V16已通过。
2. **UI草稿和保存事实分开**：编辑/预览读草稿；搜索、筛选、反向引用、导出、备份读保存版。保存期间新输入不能被捕获版本的成功误标为已保存。
3. **取消不是回滚**：Python协程被取消或Event置位不能证明SQLite事务结束。COMMIT发出后要获得明确结果或进入UNCONFIRMED；不能捕获CancelledError就称已回滚，不自动重写。
4. **回执有归属和操作类型**：只接受本集合、本命令、本笔记/版本的SAVE证据；旧集合/恢复初始化回执不能证明新SAVE，无回执也不能直接认定失败。
5. **标识不依赖名称**：双段32位十六进制引用；改名保身份、删除失效、同名重建不复活；跨集合不按名字或局部ID回退。
6. **Python码点和UTF16跨度不同**：统一使用明确转换，代码、外部链接、图片受保护；无配对代理项拒绝。名称100码点、标签30码点/20项；1000篇/10KB是性能规模，不是容量上限。
7. **SQLite显式事务**：C在专属工作线程创建/使用连接，每连接启用外键；不要用check_same_thread=False掩盖并发。关联正文/标签/引用/回执原子提交，失败后确认回滚；不支持格式版本拒绝，不自动迁移。
8. **导出/备份/恢复**：保存版为准，未保存时提示；全新草稿不可导出、备份排除仍提示。既有文件不覆盖，恢复到空位置新集合，不自动激活，不改原数据/备份。
9. **发布与激活分开**：已发布未激活仍是有效可打开集合，不作为暂存删除。放弃草稿只在真正激活后执行。必要身份登记失败/未知按状态报告。
10. **权限与Git**：账号/权限由A协调，不假定已邀请；按Issue→短期分支→PR→非作者审查→合并；A的PR由D审查。当前PR尚无组员批准，不自称已合并。
11. **依赖与离线**：开发安装可下载依赖，产品核心必须离线；不自动加载远程图片/脚本/HTML。当前Qt Essentials版本固定，新增包记录用途/版本/许可证；打包时核对Qt许可随附，不随意宣称无条件可分发。
12. **不上传个人数据**：检查.gitignore与暂存差异，个人笔记、密钥、本地数据库、日志、构建产物、私人记录、课程ZIP不上传；已跟踪文件要单独处理。
13. **版本差异**：第一关v3精确提示、扩展验收和时间规则单列待同步；语言切换已确认，业务不变量和需求编号不变。完整产品测试和Windows11人工验收后续真实执行。

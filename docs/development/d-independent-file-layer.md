## 2. 文件发布规则

调用方先取得用户选择及可信、冻结的保存数据，再在后台线程调用文件层。
`publish_bytes` 接收不可变 bytes，`publish_chunks` 接收 bytes 迭代器；不做换行转换。
它们不创建目标父目录、不直接写目标、不覆盖、不自动重试、不打开或激活集合。

暂存文件由本次调用独占创建，位于目标同一目录。写完后执行 flush/fsync、关闭，
再尝试一次非覆盖发布。Windows 使用目标存在即失败的 rename；非产品 POSIX 测试路径使用
排他硬链接创建，不能将 POSIX rename 或 os.replace 当成拒绝覆盖操作。

| 文件层结果 | 含义及调用方动作 |
|---|---|
| `OK` | 已知完整文件已发布；迟到取消不回滚。它不是 SAVE 回执，也不是集合激活证明 |
| `ERROR` | 已知没有本次发布；目标存在、暂存失败或暂存身份变化等。原目标不改 |
| `CANCELLED` | 发布前观察到取消；只尝试清理本次仍拥有的暂存文件 |
| `UNCONFIRMED` | 发布调用后无法确认效果；保留候选路径，禁止自动重发、禁止删除可能正式的文件 |

暂存清理先核对普通文件身份，不递归删除目录，不清扫其他 `.tmp` 文件。
无法安全清理时返回 `TEMPORARY_RETAINED` 警告。返回的临时路径不代表仍拥有该路径，
也不是允许调用方删除它的凭据。底层新增错误名是文件层内部细化，正式映射仍待接口对齐。

本轮针对普通本地故障与并发目标抢占；不承诺抵御恶意进程持续替换父目录、
直接改写文件内容，或所有文件系统/网络盘的掉电和断连语义。不支持的原子原语不得降级为覆盖式复制。

## 3. 导出规则与样例

命名沿用 [需求 D2/FR09](../requirements.md)：默认标题 `复习.md` 仍得到
`note-复习.md.md`，不猜测标题后缀；非法 Windows 字符只在生成默认名时替换。
自选名称非法时拒绝，不静默修正、截断、自动编号或覆盖。

渲染函数不扫描正文发现引用，不调用网络或数据库。调用方须传入来自同一保存快照、
已完成保护范围识别及身份分类的引用项。函数仅对提供的原文跨度做防御性校验和替换。
代码、图片及外链里的标记若不在获准跨度中，保持原文；分类本身须由 C 提供并联调验证。
中文、emoji、CRLF 和跨度外字符不变，目标名称中的 Markdown 特殊字符转义。

此处的纯函数测试不证明“未保存提示已接入”或“没有从草稿读取”。这些仍须由保存快照与 B 界面链路验证。

## 4. ZIP 与清单边界

ZIP 检查只读，不调用 `extractall`，不创建恢复目录，也不连接 SQLite。
允许/必需条目和资源预算由调用方显式指定；在归档解析前及流式读取时检查相应预算。
预算是技术资源保护，不是笔记数、正文或备份产品容量上限，不能从性能样本推导上限。

`manifest.json` 与 `snapshot.sqlite` 可作为显式测试策略，但这不是本阶段单方面冻结的跨模块归档格式。
本阶段不新增 manifest 字段 schema，不引入 v3 固定毫秒或恢复时刻规则。
CRC/SHA-256 一致只能辅助检查容器完整性，不证明来源可信或数据库业务有效。
合成字节即使通过容器检查，也不能作为有效笔记库或成功备份展示。

## 2026-10-19：PR #7 审查返修

本节补充后续审查结果，前文测试数量保留为首次交付历史。
审查指出：Python 的 `ZipExtFile` 会按条目声明的解压长度截断返回数据，
因此仅检查它返回的长度和 CRC，不能证明原始压缩流完整。该问题已用真实畸形 ZIP 复现，
不将旧测试通过解释为已经覆盖此边界。

修复在既有 `archive.open` 完成本地头、文件名和重叠检查后，使用同一源句柄进行额外的
原始压缩区校验，再执行原有哈希/捕获读取。DEFLATE 使用有硬输出上界的增量解压，
核对结束标记、实际长度、CRC 和压缩区剩余字节；STORED 核对完整压缩区而非声明前缀。
单条、剩余总量和剩余捕获预算均生效，不调用无输出硬上界的解压 `flush`。
这增加了一次有界校验读取，不新增源文件打开，也不是完整产品性能已达标的声明。

新增 `tests/test_d_zip_streams.py` 的 10 个真实 ZIP 测试方法。先运行旧实现时其中
7 个失败，修复后全部通过；覆盖伪小长度、1 字节预算、STORED/DEFLATE、缺失结束标记、
尾随垃圾、串联流、CRC，以及空条目、精确预算、ZIP64 和流式 data descriptor 兼容。
原 ZIP 检查 22 项也已回归，21 通过，1 项仍因 Windows 符号链接权限跳过。
容器通过不表示 SQLite 有效或恢复成功；V01—V16 完整产品验收仍未执行。
